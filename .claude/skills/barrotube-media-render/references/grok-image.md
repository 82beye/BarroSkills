# Grok Imagine image generation (browser, verified steps)

**언제 쓰나.** ChatGPT 이미지가 막혔을 때의 1순위 대안이다. ChatGPT 무료 한도는 배치
중간에 걸리고("내일 AM HH:MM까지 기능이 제한됩니다") 그 뒤로는 이미지 도구 자체가
사라진다. 그때 **결제하지 말고** 같은 캐릭터 시트를 들고 이쪽으로 넘어온다.

스틸 엔진 우선순위 (2026-08-15 확정):

| 순위 | 엔진 | 시트 첨부 | 비고 |
|---|---|---|---|
| 1 | ChatGPT 「이미지 만들기」 | ✅ 파일 첨부 | `references/chatgpt-image.md` |
| 2 | **Grok Imagine 「이미지」** | ✅ 파일 첨부 + `@` 참조 | 이 문서 |
| 3 | gpt-image-1 API | ✅ `/v1/images/edits` | auto-pipeline Phase 7 자동 폴백 |
| 4 | Gemini | 텍스트 DNA만 | 드리프트 있음 — 최후 수단 |

2026-08-15 실측: 씬 003 프롬프트를 Grok 으로 구웠더니 둥근 머리·검은 눈·주황 볼·미튼
손·캡슐 몸통이 시트대로 나왔고, 프레이밍(마시가 크게 중앙)은 오히려 ChatGPT 결과보다
좋았다. 유료 모달은 뜨지 않았다.

## Steps

1. **탭 열기.** `https://grok.com/imagine`. 로그인 계정이 ChatGPT 와 다를 수 있다.
   좌하단에 계정이 보이면 로그인 상태다.

2. **옵션 바 확인.** 프롬프트 바 아래: `+` · **이미지** · 비디오 · … · `속도|품질(v2.0)` ·
   `×4` · `9:16`. **이미지** 는 보통 이미 선택돼 있다. 끄지 말고 확인만 해라.

3. **캐릭터 시트 첨부.** 숨은 file input 에 직접 넣는다 — 클릭하면 네이티브 파일
   대화상자가 열려서 손을 못 댄다.
   - `find` 로 `input[type=file]` 를 찾아 `file_upload` 에 그 ref 를 넘긴다.
   - 컴포저에 썸네일이 뜨고 플레이스홀더가
     **「상상하려면 텍스트를 입력하세요, 이미지를 참조하려면 @」** 로 바뀌면 첨부된 것이다.

4. **⚠️ 종횡비를 9:16 으로 다시 잡는다.** 첨부하는 순간 옵션 바의 `9:16` 이 **`종횡비`
   (Auto)** 로 리셋된다. Auto 는 첨부한 시트 비율(1024×1535 ≈ 2:3)을 따라가므로 그대로
   보내면 세로 규격이 깨진다.
   - `종횡비` 를 눌러 메뉴를 열고 **9:16 수직** 을 고른다.
   - **좌표 클릭 금지 — ref 로 클릭해라.** 실측에서 메뉴 행 좌표(y=249)를 정확히 눌렀는데
     한 칸 아래 `16:9 와이드스크린` 이 선택됐다. `find "9:16 수직"` → `menuitemradio` ref
     로 클릭하면 정확히 잡힌다. 클릭 뒤 옵션 바 pill 이 `9:16` 인지 zoom 으로 확인한다.

5. **프롬프트에서 시트를 `@` 로 참조한다.** ChatGPT 와 다른 점이다 — 첨부만 해서는
   레퍼런스로 안 쓴다.
   - 텍스트박스를 클릭하고 `@` 를 친다 → **Image 1** 썸네일 선택기가 뜬다.
   - 그걸 클릭하면 `@Image1` 토큰이 박힌다. 그 뒤에 씬 설명을 이어 쓴다.
   - 헤더는 ChatGPT 경로와 같게: `@Image1 의 캐릭터 시트를 마스코트의 정확한 레퍼런스로
     써라 — 몸·얼굴·눈·볼·색·비율 동일.` + 프레이밍 규칙 + `SCENE: <image_prompt>`.

6. **생성.** 전송(↑). URL 이 `/imagine/post/<id>?conversation=<cid>` 로 바뀐다.
   전형적으로 20~40초.

7. **다운로드.** 우상단 슬라이더 아이콘을 눌러 액션 패널을 연다
   (`정밀 편집 · Colors · Remove Background · 재생성 · 동영상 만들기 · 자르기 · 종횡비 · 공유`),
   맨 아래 줄의 **⬇ 아이콘**을 누른다.
   - 저장 이름은 `~/Downloads/grok-image-<postId>.jpg` — **postId 가 URL 의 것과 같은지**
     대조하면 이전 실행 파일을 잘못 집는 사고를 막을 수 있다.
   - **programmatic blob 다운로드는 안 된다.** `assets.grok.com` 이 CORS 로 막아
     페이지 컨텍스트 `fetch()` 가 **0 바이트** 를 돌려준다(실측). ChatGPT 경로의 Blob
     폴백을 여기 그대로 가져다 쓰지 마라 — 빈 파일이 생긴다.

8. **PNG 로 변환해 저장.** Grok 은 **JPEG** 를 준다. 파이프라인은 `scene_NNN.png` 를 본다.
   ```bash
   python3 -c "from PIL import Image; Image.open('$HOME/Downloads/grok-image-<id>.jpg') \
     .convert('RGB').save('<base>/40_assets/images/scene_<NNN>.png')"
   ```

9. **검증.** `1008x1792` (= 정확히 9:16) 이 정상 출력이다. `file` 로 크기를 확인하고,
   마시가 온모델인지(둥근 머리·검은 눈·주황 볼·미튼 손·맨몸 크림화이트) 눈으로 본다.

## 캐릭터 시트를 Grok 으로 만들거나 보강할 때

시트(`~/BarroTubeData/workspace/docs/바로경제_캐릭터시트.png`)는 **모든 씬 이미지의 기준점**
이라 자주 건드릴 물건이 아니다. 다만 새 채널을 열거나 표정·포즈 칸을 넓혀야 할 때가 있다.

- **기존 시트를 확장하는 게 새로 그리는 것보다 안전하다.** 현재 시트를 첨부하고
  `@Image1` 로 참조한 뒤 "같은 캐릭터·같은 화풍으로 표정 칸만 추가" 를 시킨다. 처음부터
  다시 그리게 하면 이미 발행된 영상들과 캐릭터가 어긋난다.
- **종횡비는 시트용으로 `1:1` 또는 `2:3` 을 고른다.** 시트는 씬이 아니라 격자판이라
  9:16 이 아니다. (씬 스틸만 9:16 이다.)
- 시트 구성은 `character-dna.md` 가 정본이다. 현재 판은 5블록:
  `1 MAIN CHARACTER / 2 TURNAROUND(front·3q·side·back) / 3 EXPRESSIONS(neutral·happy·surprised·
  inspired·determined·crying) / 4 ACTION POSES(standing·walking·running·pointing·cheering·
  presenting) / 5 STYLE GUIDE STRIP(color palette)`.
- **새 시트를 채택하기 전에 반드시 대조한다.** 몸통/머리 폭 비율이 발행본 밴드
  **0.57~0.68** 안에 들어야 한다. 벗어나면 채택하지 마라 — 그 밖으로 나가면 마시가
  뚱뚱해지고, 그 상태로 굳으면 모든 후속 회차가 따라간다.
- 채택하면 **이전 시트를 지우지 말고** 날짜 접미사로 남긴다
  (`바로경제_캐릭터시트.2026-08-15.png`). 드리프트가 의심될 때 되돌릴 근거가 된다.

프롬프트도 Grok 에게 시킬 수 있다. 다만 씬의 `image_prompt` 는 대본 작성 단계(S4)의
산출물이고 `references/IMAGE-PROMPT.md` 계약(길이·마스코트 주어 비율·금지어)을 통과해야
하므로, 브라우저에서 즉흥으로 지어내지 마라. 대본에 있는 것을 그대로 쓴다.

## Gotchas

- **종횡비 리셋이 가장 흔한 사고다.** 시트를 붙일 때마다 Auto 로 돌아간다. 컷마다 다시 잡아라.
- **`@` 를 빼먹으면 시트가 무시된다.** 첨부 썸네일이 보인다고 참조된 게 아니다.
  ChatGPT 는 첨부만으로 되지만 Grok 은 아니다.
- **메뉴는 ref 로 클릭.** 좌표가 한 행씩 밀린다(실측).
- **SuperGrok 유료 모달.** 쿼터가 소진되면 구독 모달이 뜬다. **결제·무료 체험 절대 금지.**
  X 로 닫고 「Grok 쿼터 소진」 이라고 보고하면 auto-pipeline 이 gpt-image-1 API 로 넘어간다.
- **다운로드는 JPEG.** EXIF 에 AI 서명이 박혀 있다. 변환 시 `convert('RGB')` 로 떨군다.
- **`동영상 만들기` 가 같은 패널에 있다.** 스틸을 승인한 뒤 곧바로 image→video 로 이어갈 수
  있다 — 절차는 `references/grok-video.md`.
