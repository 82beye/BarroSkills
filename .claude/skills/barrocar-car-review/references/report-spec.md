# 구매 검토 의견서 규격

`assets/report-template.html`을 채운다. 기본 파일명은 `중고차_진단의견서_{차량번호}.html`, 기본 저장 경로는 `/Users/beye/workspace/BarroCar/`이다. 사용자가 지정한 경로가 우선한다. 원문 응답·자료와 URL·수집시각은 같은 위치의 `{문서명}_sources/`에 보관한다. 기존 의견서 수정 시 원본을 보관하고 개정 사유를 적는다.

## 구성

브랜드·표제 → 메타 → **신뢰 패널** → 판정/심사 상태 → 검토 소견 → 등급 바 → ①~⑩ → 서명 → 검증 블록 → 유의사항.

| 영역 | 내용 |
|---|---|
| 메타 | 문서번호, 작성·수집시각, 확인된 차량번호/VIN, 검토 범위 |
| 신뢰 패널 | 플랫폼별 수집량·실제 심사량·미완료, 근거 등급 집계, 추적 가능한 출처 |
| 판정 | 완료한 심사의 계약 진행 / 대안 우선 / 구매 금지. 미완료면 최종 판정 미발행 표시 |
| 검토 소견 | 3~5문장: 근거 있는 결론, 자료 한계, 다음 행동 |
| 등급 바 | 차체·파워트레인·이력 투명성·미확인 항목. 미확인은 양호로 표시하지 않음 |
| ① 대상 | 확인된 제원·호가·판매조건·사용자 조건. API 광고값은 판매자 정보 |
| ② 게이트 | F1~F5, S1~S8, 각 결과와 근거. 중복 대조표 포함 |
| ③ 사고 판독 | 부위·랭크·X/W 등 수리 표기. 기록상 사고 없음과 실제 무사고 구분 |
| ④ 보험 | 내차/타차, 날짜, 총수리비, 부품·공임·도장, 보험금, 합계·건수 대조 |
| ⑤ 이력 | 날짜×주행, 발급일, 특수·용도·소유·자차공백·리콜, 불일치 |
| ⑥ 시세 | 적격 비교군, 연식·주행·옵션 차이, 호가임을 명시. 3대 미만 또는 중복 미해결이면 유보 |
| ⑦ 예상 비용 | 견적·공식 자료에 근거한 지출과 가정별 시나리오. 근거 없으면 산정 불가 |
| ⑧ 대안 | 본건과 실제 후보의 동일 기준 심사. 적격 후보만 순위 부여 |
| ⑨ 확인 사항 | 필수 원문·검수·계약조건 체크박스. 미확인 핵심 항목은 계약 전에 해결 |
| ⑩ 최종 의견 | 판정 또는 미완료 상태, 대안 결과, 근거 있는 다음 행동 |
| 검증 블록 | 생성 조건·시각·실제 심사량·출처 위치·개정·유효 범위 |

신뢰 패널·검증 블록·⑧·⑩은 생략하지 않는다. ⑧에 후보가 없으면 조사 조건·실제 조회 수·실패/미완료를 쓴다. ④는 0건이 확인되면 간략한 무기록 요약으로 대체할 수 있다. VIN·압류·저당 등을 조회하지 않았다면 수치를 만들어 채우지 않는다.

## 판정·문장

3분법과 완료 조건은 `../SKILL.md`를 따른다. «조건부»는 최종 판정 명칭으로 쓰지 않는다. 필수 근거가 남으면 «심사 미완료 — 최종 판정 미발행»을 명시한다. 미확인 매물에 구매 명령이나 적격 순위를 부여하지 않는다.

| 상태 | 권장 색상 클래스 |
|---|---|
| 계약 진행 | `v-good` |
| 대안 우선 | `v-cond` |
| 구매 금지 | `v-bad` |
| 심사 미완료 | `v-pending` |

가격 판정은 저평가/적정/고평가/판정 유보다. 본문과 표시 클래스가 일치해야 한다. 차체·파워트레인 등급에는 미확인도 허용한다.

실제 경력·실차 점검이 없는 작성자를 «30년 명장»으로 소개하지 않는다. 확인한 사실은 직접 쓰고, 추정은 추정으로 쓴다. 보고서 모양·직인·«검증» 라벨이 전문가 검수나 자동 사실 검증 완료를 의미하지 않게 한다.

## 근거와 출처

[기록]/[판매자]/[추정]/[미확인]이 기본 등급이다. [제원]/[리뷰]는 출처가 있는 보조 등급이다. 원문 URL·파일·페이지·필드로 개별 주장을 추적할 수 있어야 한다. 사이트 이름만 적거나 근거 태그만 붙이는 것으로 검증이 되지 않는다.

«딜러 제공 자료를 옮겨 적지 않았다», «API 직접 확인», «전수 조회»는 **실제로 수행한 경우만** 쓴다. API의 광고 필드도 판매자가 입력한 정보일 수 있다. 사용자 캡처·광고·리뷰 등 실제 수집 경로를 그대로 밝힌다.

신뢰 패널 밖 **가시 본문에 등장하는 등급 토큰**을 센다. HTML 속성·주석·스타일·스크립트와 신뢰 패널 자체는 제외한다. 반복 표기는 주장 토큰 수이며 독립된 증거 수가 아니다. 템플릿의 `data-count-grade`와 `data-count-total`에는 완성 후 계산한 정수를 넣는다. [제원]·[리뷰] 칸은 두 토큰 수의 합이다.

```bash
python3 assets/check_report.py '/Users/beye/workspace/BarroCar/중고차_진단의견서_차량번호.html'
```

이 명령은 미치환 항목·집계·필수 영역 등을 검사하고 오류 시 비정상 종료한다. 실제 사실·안전성·전수 수집 여부를 입증하지 않는다. 원문 대조와 HTML 열기·인쇄 미리보기도 수행한다.

## 커버리지 퍼널

각 단계의 분모·분자를 실제 처리 수로 계산한다. 수집 광고 수, 동일차 확인 후 차량 수, 조건 부합 수, 실제 서류 심사 수를 구분한다. 미조회·보류·제외는 숨기지 않고 각 단계 합이 분모와 일치하게 한다. 전 단계 전체가 분모인 경우와 단계별 분모를 섞지 않는다. 빈 단계는 0/0 대신 해당 없음으로 표시한다. 너비의 최소값으로 비율을 부풀리지 않는다.

## 링크·중복

모든 광고ID는 플랫폼 배지와 올바른 상세 URL로 연결한다.

- 엔카: `https://fem.encar.com/cars/detail/{광고ID}`
- KB: `https://www.kbchachacha.com/public/car/detail.kbc?carSeq={id}`
- 케이카 마켓: `https://market.kcar.com/ds/detail/adInfoDtl/{ccCarId}`

광고ID와 차량ID가 다르면 병기하되 링크는 광고ID로 건다. 링크는 `.lnk`, `target="_blank" rel="noopener"`를 사용한다. 외부 텍스트는 HTML 이스케이프하고 링크 스킴은 확인된 http(s)만 허용한다. 출처 파일의 로컬 링크도 출력 환경에서 열리는지 확인한다.

중복 대조표는 플랫폼·광고ID·호가·확정 근거를 적는다. 동일 VIN/차량번호 등 확인 없이 연식·주행·가격만 일치한 매물은 «동일 차량 후보 [추정]»로 남긴다. 확정 중복이 없으면 «확정된 중복 없음»과 미확인 여부를 구분한다. 후보표 순위는 1/2/3순위, 제외, 심사 미완료를 사용한다.

## 시세·비용

비교표에 각 차량의 등록일·모델연도·주행·트림·좌석 차이를 적는다. 광고 호가와 실거래가는 다르며 가격 차이 전부를 사고 감가로 계산하지 않는다. 실제 견적 없는 지출을 «확정»으로 표시하지 않는다. 유지비·매각가·고장비용은 조건과 범위를 밝히며, 불확실한 항목을 누락한 합계를 총 보유비용으로 부르지 않는다.

자동차세는 모든 차량에 `배기량 × 200 × 1.3`을 적용하지 않는다. [지방세법 제127조](https://law.go.kr/LSW/lsSideInfoP.do?docCls=jo&joBrNo=00&joNo=0127&lsiSeq=282559&urlMode=lsScJoRltInfoR)의 현행 세율, 등록상 차종·용도, 배기량, 반기별 차령·보유기간, 지방교육세와 감면을 확인한다. 비영업용 일반 승용의 배기량별 세율은 1,000cc 이하 80원, 1,600cc 이하 140원, 초과 200원이며 차량별 계산 조건을 별도 명시한다. 전기·승합·영업용 등을 같은 식으로 계산하지 않는다. 조건이 빠지면 참고 계산으로 표시한다.

## 확인 사항과 유효 범위

확인해야 할 핵심 항목은 `chk crit`, 일반 항목은 `chk`로 표시하고 이유를 한 줄씩 쓴다. 미확인 핵심 근거를 체크리스트로 이동시켰다는 이유로 최종 판정을 확정하지 않는다.

검증 블록은 문서번호·생성 방식(수집기 일부 자동 요약 + 자료 검토)·수집/생성시각·차량·실제 심사 수·출처 위치·개정 사유·유효 범위를 표시한다. «서류 검토용, 실차 미점검. 매물과 가격은 변하므로 계약 전 재조회»를 명시한다.

유의사항에는 비공식 참고 의견서, 실제 검토 범위, 보험 이력 부재의 한계, 견적/호가의 불확실성, 공식 제원·리콜·정비·계약조건 확인, 구매자의 최종 결정을 포함한다. 책임이 없다고 선언해 허위 사실이나 근거 없는 구매 지시를 정당화하지 않는다.

## 서식

현재 템플릿의 인쇄·모바일 레이아웃과 폰트 폴백을 유지한다. 표의 통과/탈락/보류/순위는 `b-pass`/`b-fail`/`b-warn`/`b-rank` 배지를 사용한다. 미확인·미심사에 통과색을 쓰지 않는다. 구버전 `.v1.bak`은 출력에 사용하지 않는다.
