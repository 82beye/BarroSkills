# BarroCar 소거 게이트

F1~F5는 BarroCar의 보수적 선별 기준, S1~S8은 비교 요소다. 법정 안전 기준·차량 고장 확률로 오해하지 않도록 출처와 판단 범위를 밝힌다. 숫자 기준은 검증된 안전 보증 임계값이 아니다.

## 하드 게이트

### F1 · 서류

성능·상태점검기록부와 보험이력의 **실제 내용**을 확인한다.

- 원문과 필요한 건별 내역이 있고 정합성 확인 → 통과.
- 공개 거부 또는 실제 미공개가 확인됨 → 해당 자료 조건에서 탈락. 원문 확보 후 재심사.
- HTTP 오류, 빈 내용의 서식, 누락된 금액·필드, 파싱 실패 → 보류. 공개 거부로 추정하지 않는다.
- 개인정보 가림과 차량 상태 필수 내용의 누락을 구분한다. 미공개만으로 판매자의 기만·차량 결함을 단정하지 않는다.
- 보험사고 0건은 요약 건수·금액·건별 배열에서 확인한다. 사고가 있는데 세부가 0원이고 지급액이 있으면 내역 불충분으로 다룬다.

### F2 · 주요 골격과 외판 2랭크

`damage-taxonomy.md`의 **부위와 수리 방식**을 함께 적용한다.

- 주요 골격의 사고 관련 교환·판금/용접이 확인됨 → 탈락.
- 외판 1랭크만 교환·판금이며 주요 골격 기록이 정상적으로 확인됨 → F2 통과. 현재 차량 상태 전체가 정상이라는 뜻은 아니다.
- 쿼터·루프·사이드실은 서식상 외판 2랭크다. 절단·용접이 확인되면 탈락, 판금만임이 확인되면 다른 이력과 함께 검토한다. W는 판금/용접을 함께 뜻하므로 이것만으로 둘을 구별하지 않는다. 자동 수집기는 이 부위를 보류한다.
- `seriousTypes`는 골격이 아닌 특별이력이다. 특별이력이 있으면 추가 확인을 위해 자동 F2는 보류하되 골격 손상으로 단정하지 않는다. `outers`에도 주요 골격이 들어온다. 부위 불명·기록 충돌·필수 항목 누락은 보류.

골격 이력이 있으면 복원 품질·안전성을 문서만으로 보증할 수 없어 선별에서 제외한다. «충돌 흡수 성능이 반드시 무너졌다»고 확정하지 않는다. 탈락을 뒤집는 고정 감가율은 제시하지 않는다.

### F3 · 사고 관련 현가·구동계 수리

쇼크업소버·로어암·너클·프로펠러샤프트·등속조인트·디퍼렌셜·트랜스퍼케이스 등의 **사고 관련 손상·수리**를 확인한다.

- 정비명세서·보험 상세·공식센터 자료 등으로 사고 관련성이 확인됨 → 탈락.
- 정비명세서 또는 공식센터 이력을 확보했고, 그 안에 **사고 관련 현가·구동계 수리가 없음**이 확인됨 → 통과.
- 사고와 무관한 소모품·예방 정비임이 확인됨 → 그 교체 자체는 탈락 사유가 아니다.
- 같은 날짜에 부품명이 나왔다는 이유만으로 사고 관련성을 확정하지 않는다.
- 공개 보험이력에 **내차·타차 사고가 모두 없고**, 성능기록부의 **동력전달·조향·제동 항목을 실제로 조회해 이상 표기가 없으면** «해당 없음 — 공개 기록 범위»로 적을 수 있다. 사고가 없으면 «사고 관련 수리»의 대상이 없기 때문이며, F4와 같은 처리다. **이는 통과가 아니라 게이트의 대상이 아니라는 뜻이고, 무수리 보증도 아니다** — 보험에 접수하지 않은 수리는 이 범위 밖이므로 근거와 한계를 의견서에 함께 쓰고 실차 확인 항목으로 이관한다.
- 위 조건을 채우지 못하면 → 보류 [미확인]. **타차피해만 있는 경우도 충돌 자체는 있었으므로 해당 없음으로 적지 않고 보류한다.** 점검 항목을 조회하지 못했거나 자료가 충돌해도 보류다. 보험사고 0건·현재 점검 «양호»만으로 과거 사고 수리 부재가 입증되지는 않는다.

### F4 · 확인된 사고 수리 후 주행

`현재 기재 주행거리 − 사고 수리 시점의 실제 기재 주행거리`로 계산한다. 두 기록의 날짜·차량 일치를 확인한다. 음수나 불일치는 보류하고 원문을 재확인한다.

| 확인된 차이 | BarroCar 선별 처리 |
|---|---|
| 5,000km 미만 | 수리 후 사용 근거가 부족하므로 탈락 |
| 5,000~15,000km 미만 | 보류. 외판 수리만임과 필요한 점검 결과를 확인해 재심사 |
| 15,000km 이상 | 이 선별 항목 통과. 수리 품질·현재 안전성의 보증은 아님 |
| 사고 시점 주행거리 미확보 | 보류. 연평균 주행·경과일로 추정한 값은 판정에 사용하지 않음 |

공개 기록에 사고 수리 건이 없으면 «해당 없음 — 공개 기록 범위»로 적을 수 있다. 실제 사고가 없었다는 단정이나 F3 통과 근거로 사용하지 않는다. 30,000km를 달렸다고 검증 완료로 쓰지 않는다.

### F5 · 용도이력

- 보험이력 또는 등록자료에 렌트·영업용·관용 이력이 확인됨 → BarroCar 기준 탈락.
- 각 항목에서 이력 없음이 확인됨 → 통과.
- 항목 누락·미조회 → 보류. 누락값을 0으로 바꾸지 않는다.
- 법인 업무용은 렌트와 구분하며, 관리 자료를 S1에서 검토한다.

용도만으로 난폭 운전·사고 은폐·DPF 손상을 사실로 서술하지 않는다.

## 소프트 게이트

| 항목 | 확인·비교 방법 |
|---|---|
| S1 소유 이력 | 소유변경 횟수·시점과 실제 사용자 수를 구분한다. 매매업자 이전이 포함될 수 있다. 0회만으로 관리 우수·무수리를 보증하지 않는다 |
| S2 주행거리 | 실제 운행 기간과 정비내역을 함께 본다. 연 1~2만km는 비교용 참고 범위. 저주행만으로 방치, 고주행만으로 고속도로 주행이나 수명을 추정하지 않는다 |
| S3 사고 규모 | 내차/타차와 수리 부위를 구분한다. 금액 임계값만으로 무사고·경미 사고·정상 차량 판정을 하지 않는다 |
| S4 플랫폼 진단 | 실제 진단 내용·발급일·제외 항목을 확인한다. 서비스마다 범위가 다르며, 진단 가입 자체는 무결함 증거가 아니다 |
| S5 자차담보 공백 | 명시된 기간을 기록한다. 자차 미가입과 자동차보험 전체 미가입은 다르다. 공백 없음도 비보험 수리를 배제하지 못한다 |
| S6 리콜 | 기록의 대상·이행 여부와 조회 시점을 밝힌다. 누락은 미확인. VIN 기준 공식 조회와 광고가 다르면 확인 전까지 보류한다 |
| S7 판매자 | 실제 환불·보증·비용·계약 조건을 확인한다. 직영·개인이라는 이유만으로 보호 범위·품질을 단정하지 않는다 |
| S8 가격 | 동일 조건의 유효 비교군 3대 이상, 광고 중복과 승계금 제외, 호가와 실거래 구분. 과도한 저가의 이유가 확인되지 않으면 가격 판정 유보 |

[카히스토리 안내](https://www.carhistory.or.kr/guide/sample.page)는 보험사에 접수·처리되지 않은 사고가 제공 범위에 포함되지 않음을 밝힌다. 사고 0건·자차 공백 0일은 그 범위 안의 기록으로만 해석한다.

## 판정 종합

최종 판정은 **계약 진행 / 대안 우선 / 구매 금지**다. 세부 조건은 `../SKILL.md`의 최종 판정 표를 따른다. 확인된 하드 게이트 탈락은 가격으로 뒤집지 않는다. 미확인은 탈락 증거도 통과 증거도 아니다. 필요한 근거가 남으면 «심사 미완료 — 최종 판정 미발행»으로 보고한다.

## 적용 예시 (설명용 가상 입력)

- 골격 판금과 사고 관련 구동계 수리가 원문에서 확인됨 → F2·F3 탈락, 구매 금지. 저렴한 가격으로 상쇄하지 않는다.
- 보험사고 0건(내차·타차 모두), 자차 공백 없음, 동력전달·조향·제동 점검 이상 없음, 정비자료 미확보 → F3·F4 모두 «해당 없음 — 공개 기록 범위». 서류 기준 게이트는 정리되며, 남은 것은 ⑨의 실차 확인 항목이다.
- 타차피해 1건, 내차 기록 0건, 정비자료 미확보 → F4는 해당 없음이지만 **F3는 보류**다. 충돌이 있었으므로 그때 현가·구동계에 영향이 있었는지 확인해야 한다.
- 실제 사고 시점 주행거리 미확보, 연평균으로 계산한 수리 후 주행 2만km → F4 보류. 2만km 추정값을 통과 근거로 사용하지 않는다.
